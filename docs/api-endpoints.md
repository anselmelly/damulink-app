# API endpoints

Generated by `node scripts/api-docs.mjs` from the route files; do not edit by hand. Conventions (auth, errors, formats) are in [api.md](api.md).

Auth column: **public** needs no login; **login** needs a valid `X-Auth` token; **super admin** needs a super admin. Facility routes also check that the caller belongs to the facility, and some need the facility admin or a permission.
